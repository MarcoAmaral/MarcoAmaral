# Sources

The images in `assets/` are stored in this repo so the profile doesn't depend on outside services.

- `banner.html` renders `banner-light.png`; open it with `?dark` for `banner-dark.png`. Screenshot at 1280×320 with device scale 2 (2560×640).
- `typing-*.svg` were generated once by readme-typing-svg (IBM Plex Mono 500, size 17, colors 13233F light / CFE0FF dark).
- `badge-*.svg` were generated once by shields.io (`style=for-the-badge`).
